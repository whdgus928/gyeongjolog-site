2. 사진·파일 가져오기와 권한

사용자가 선택한 사진, 엑셀·CSV 파일 및 붙여넣은 텍스트를 기록으로 변환합니다. 사진의 문자 인식은 Google ML Kit를 이용해 기기에서 수행합니다. 가져오기 원본 사진·파일 자체를 경조로그 기록 저장 서버로 업로드하지 않으며, 확인 후 저장한 이름·금액·날짜 등의 기록은 서버 동기화 대상입니다.

알림 권한은 일정 알림에 사용하며 사용자가 거부하거나 기기 설정에서 변경할 수 있습니다. 앱은 사용자가 선택하지 않은 사진·파일이나 기기 연락처를 임의로 읽지 않습니다.

3. 저장 위치와 보관 기간

기록은 기기 내 저장소와 Supabase 서버에 저장됩니다. 계정에 연결된 기록은 삭제 또는 계정 삭제 요청이 처리될 때까지 보관됩니다. 앱 삭제만으로 서버 데이터가 삭제되지는 않습니다. 게스트 상태에서 앱을 삭제하면 익명 계정 접근 정보를 잃어 기록 복구가 어려울 수 있습니다.

복구용으로 최근 기록 스냅샷을 최대 20개 보관합니다. 새 백업 생성 시 오래된 백업을 정리하므로, 개별 기록을 삭제하더라도 이전 백업에는 해당 기록이 남을 수 있습니다. 기간이 지나면 자동으로 삭제되는 방식은 아닙니다. 백업까지 삭제하려면 아래의 전체 데이터 또는 계정 삭제 요청을 이용해 주세요.
